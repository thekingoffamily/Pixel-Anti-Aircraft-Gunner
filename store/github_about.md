## Промпт для генерации логотипа

```text
Квадратный логотип для мобильной Android-игры «Пиксельный Зенитчик».

Стиль: качественный 16-битный pixel art, ретро-аркада, высокая детализация,
контрастные крупные пиксели, формат 1:1, подходит для иконки APK.

В центре — футуристичная зенитная турель, направленная по диагонали вверх.
Турель выпускает яркие голубые пиксельные снаряды в сторону нескольких
абстрактных вражеских дронов в ночном небе. На фоне — тёмно-фиолетовое небо,
блочные облака, силуэт защитного бункера или города, оранжевые пиксельные
взрывы.

Добавить крупный, полностью читаемый русский заголовок:
«ПИКСЕЛЬНЫЙ ЗЕНИТЧИК»
Шрифт — массивный пиксельный, без ошибок в кириллице.

Без флагов, реальных государственных символов, настоящих военных знаков,
людей, политических отсылок и названий стран.
```
